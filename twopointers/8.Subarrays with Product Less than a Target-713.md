# Intuition
A brute-force approach would generate every possible contiguous subarray, calculate its product, and count those with a product less than `k`. However, this requires checking all subarrays, resulting in **O(n²)** time complexity.
Since all numbers in the array are positive, the product of the current window only increases when we expand the window. If the product becomes greater than or equal to `k`, we can shrink the window from the left until the product becomes valid again. This observation makes the **Sliding Window (Two Pointers)** technique an optimal solution.

# Approach
1. If `k <= 1`, return `0` because no positive product can be less than `1`.
2. Initialize:
   - `left = 0` to represent the left boundary of the window.
   - `product = 1` to store the product of the current window.
   - `count = 0` to store the total number of valid subarrays.
3. Traverse the array using the `right` pointer:
   - Multiply the current element with `product`.
   - While the product is greater than or equal to `k`, divide out the leftmost element and move `left` forward.
4. After the window becomes valid, every subarray ending at `right` and starting anywhere from `left` to `right` is valid.
   - Number of such subarrays = `right - left + 1`.
5. Add this value to `count`.
6. Return `count`.

# Complexity
- **Time complexity:** `O(n)`
  - Each element is visited at most twice (once by `right` and once by `left`).

- **Space complexity:** `O(1)`
  - Only a few variables are used regardless of the input size.

# Code
```python
class Solution:
    def numSubarrayProductLessThanK(self, nums, k):
        if k <= 1:
            return 0

        product = 1
        left = 0
        count = 0

        for right in range(len(nums)):
            product *= nums[right]

            while product >= k:
                product //= nums[left]
                left += 1

            count += right - left + 1

        return count
```
