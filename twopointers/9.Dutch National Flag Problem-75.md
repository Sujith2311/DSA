# Dutch National Flag Problem (LeetCode 75)

## Intuition
Since the array contains only three distinct values (`0`, `1`, and `2`), we can simply sort the array to arrange them in ascending order. This solution uses the **Selection Sort** algorithm, where in each iteration we find the smallest element from the unsorted portion of the array and place it at its correct position.

Although this is not the optimal solution for this problem, it correctly sorts the colors.

## Approach
- Traverse the array from left to right.
- For each position `i`, assume it contains the minimum element.
- Search the remaining unsorted portion of the array to find the actual minimum element.
- Swap the minimum element with the element at index `i`.
- Repeat this process until the array is completely sorted.

## Complexity

- **Time complexity:**  
  **O(n²)**

- **Space complexity:**  
  **O(1)**

## Code

```cpp
class Solution {
public:
    void sortColors(vector<int>& nums) {
        int n = nums.size();

        for (int i = 0; i < n - 1; i++) {
            int min = i;

            for (int j = i + 1; j < n; j++) {
                if (nums[j] < nums[min]) {
                    min = j;
                }
            }

            swap(nums[i], nums[min]);
        }
    }
};
```
