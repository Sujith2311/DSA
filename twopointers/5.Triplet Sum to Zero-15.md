# Intuition

A brute-force approach checks every possible triplet, resulting in **O(n³)** time complexity.

To optimize this, we first **sort the array**. Once sorted, we can fix one element and use the **Two Pointers** technique to efficiently find the other two elements whose sum makes the total equal to `0`.

Sorting also makes it easy to skip duplicate values, ensuring that the final answer contains only unique triplets.

---

# Approach

1. Sort the array.
2. Iterate through each element and treat it as the first element of the triplet.
3. Skip duplicate values for the fixed element to avoid duplicate triplets.
4. Initialize two pointers:
   - `left = i + 1`
   - `right = n - 1`
5. Calculate:
   ```python
   total = nums[i] + nums[left] + nums[right]
   ```
6. If:
   - `total == 0`
     - Add the triplet to the answer.
     - Move both pointers.
     - Skip duplicate values for both pointers.
   - `total < 0`
     - Increase the sum by moving `left` forward.
   - `total > 0`
     - Decrease the sum by moving `right` backward.
7. Continue until all unique triplets are found.

---

# Code

```python
class Solution:
    def threeSum(self, nums):
        nums.sort()
        ans = []
        n = len(nums)

        for i in range(n - 2):

            if i > 0 and nums[i] == nums[i - 1]:
                continue

            left = i + 1
            right = n - 1

            while left < right:

                total = nums[i] + nums[left] + nums[right]

                if total == 0:
                    ans.append([nums[i], nums[left], nums[right]])

                    left += 1
                    right -= 1

                    while left < right and nums[left] == nums[left - 1]:
                        left += 1

                    while left < right and nums[right] == nums[right + 1]:
                        right -= 1

                elif total < 0:
                    left += 1

                else:
                    right -= 1

        return ans
```

---

# Complexity

- **Time Complexity:** `O(n²)`
  - Sorting takes `O(n log n)`.
  - For each element, the two pointers traverse the remaining array once, resulting in `O(n²)` overall.

- **Space Complexity:** `O(1)`
  - No extra space is used apart from the output list.
