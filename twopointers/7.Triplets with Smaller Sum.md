# Count Triplets With Sum Smaller Than Target

## Intuition

A brute-force solution checks every possible triplet using three nested loops, resulting in **O(n³)** time complexity.

Since the array contains distinct integers, we can optimize the solution by first **sorting** the array and then using the **Two Pointer** technique.

The key observation is:

- After sorting, fix one element `arr[i]`.
- Use two pointers:
  - `left = i + 1`
  - `right = n - 1`
- Calculate the current triplet sum.

If the current sum is **less than the target**, then **every element between `left` and `right` will also form a valid triplet with `arr[i]`**, because the array is sorted.

Instead of checking each one individually, we can directly count:

```text
right - left
```

This observation reduces the complexity from **O(n³)** to **O(n²)**.

---

## Approach

1. Sort the array.
2. Initialize `count = 0`.
3. Iterate through the array and fix one element (`i`).
4. Place two pointers:
   - `left = i + 1`
   - `right = n - 1`
5. While `left < right`:
   - Compute the current sum.
   - If the sum is smaller than the target:
     - Add `(right - left)` to the answer.
     - Move `left` forward.
   - Otherwise:
     - Move `right` backward.
6. Return the final count.

---

## Python Code

```python
class Solution:
    def countTriplets(self, arr, target):
        arr.sort()
        n = len(arr)
        count = 0

        for i in range(n - 2):
            left = i + 1
            right = n - 1

            while left < right:
                current_sum = arr[i] + arr[left] + arr[right]

                if current_sum < target:
                    count += (right - left)
                    left += 1
                else:
                    right -= 1

        return count
```

---

## Example

### Input

```text
arr = [-2, 0, 1, 3]
target = 2
```

### Sorted Array

```text
[-2, 0, 1, 3]
```

### Valid Triplets

```text
(-2, 0, 1)
(-2, 0, 3)
```

### Output

```text
2
```

---

## Complexity Analysis

- **Time Complexity:** `O(n²)`
  - Sorting takes **O(n log n)**.
  - The outer loop runs `n` times.
  - The two pointers together traverse the array only once for each fixed element.
  - Overall complexity is **O(n²)**.

- **Space Complexity:** `O(1)`
  - No extra space is used apart from a few variables.
  - (Ignoring the space used by the sorting algorithm.)

---

## Key Observation

Whenever:

```text
arr[i] + arr[left] + arr[right] < target
```

then every index between `left` and `right` also forms a valid triplet.

So instead of checking them one by one, simply do:

```python
count += (right - left)
```

This single optimization is what makes the solution efficient.
