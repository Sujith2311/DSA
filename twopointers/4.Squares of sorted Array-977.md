# Intuition
The square of a negative number becomes positive, so after squaring the elements, the array may no longer remain sorted. Therefore, we square each element first and then sort the resulting array.

# Approach
1. Create an empty list `ans`.
2. Traverse the input array.
3. Square each element and append it to `ans`.
4. Sort the `ans` list.
5. Return the sorted list.

# Complexity
- Time complexity:
  - Squaring all elements takes **O(n)**.
  - Sorting the squared array takes **O(n log n)**.
  - Overall: **O(n log n)**.

- Space complexity:
  - We use an additional list to store the squared values.
  - **O(n)**.

# Code
```python
class Solution:
    def sortedSquares(self, nums):
        ans = []
        for x in nums:
            ans.append(x * x)
        ans.sort()
        return ans
