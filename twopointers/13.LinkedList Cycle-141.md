# Intuition

If a linked list contains a cycle, two pointers moving at different speeds will eventually meet inside the loop.

- Use a **slow pointer** that moves one node at a time.
- Use a **fast pointer** that moves two nodes at a time.
- If there is no cycle, the fast pointer will reach the end (`None`).
- If there is a cycle, the fast pointer will eventually catch up to the slow pointer.

This approach is known as **Floyd's Cycle Detection Algorithm (Tortoise and Hare Algorithm).**

# Approach

1. Initialize two pointers, `slow` and `fast`, at the head of the linked list.
2. Traverse the list while `fast` and `fast.next` are not `None`.
3. Move:
   - `slow` by one step.
   - `fast` by two steps.
4. If `slow == fast`, a cycle exists, so return `True`.
5. If the loop ends, the fast pointer reached the end of the list, meaning there is no cycle. Return `False`.

# Complexity

- **Time complexity:** `O(n)`
  - In the worst case, each node is visited at most a constant number of times.

- **Space complexity:** `O(1)`
  - Only two pointers are used, so no extra space is required.

# Code

```python
class Solution(object):
    def hasCycle(self, head):
        slow=head
        fast=head
        while fast and fast.next:
            slow=slow.next
            fast=fast.next.next
            if slow==fast:
                return True
        return False
```
