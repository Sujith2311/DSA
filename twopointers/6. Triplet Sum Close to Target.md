# Triplet Sum Close to Target

🔗 **Pattern:** Two Pointers

---

# Intuition

A brute force solution would generate every possible triplet and calculate its sum. For each triplet, we compare how close it is to the target and keep track of the closest one.

This requires checking all possible triplets, leading to a time complexity of **O(n³)**.

A more efficient approach is to first **sort the array**. After fixing one element, we can use the **two-pointer technique** to find the other two elements.

Since the array is sorted:

- If the current sum is smaller than the target, move the **left pointer** to increase the sum.
- If the current sum is greater than the target, move the **right pointer** to decrease the sum.
- Continuously update the closest sum whenever we find a better candidate.

This reduces the time complexity to **O(n²)**.

---

# Approach

1. Sort the array.
2. Initialize a variable `closestSum` to store the closest triplet sum.
3. Iterate through the array and fix one element.
4. Use two pointers:
   - `left = i + 1`
   - `right = n - 1`
5. Calculate the current triplet sum.
6. Update `closestSum` if the current sum is closer to the target.
7. If both sums are equally close, keep the **smaller sum**.
8. Move:
   - `left++` if the current sum is less than the target.
   - `right--` if the current sum is greater than the target.
9. If the current sum equals the target, return it immediately.
10. Return `closestSum`.

---

# Python

```python
class Solution:
    def searchTriplet(self, arr, target):
        arr.sort()
        closestSum = float('inf')
        for i in range(len(arr) - 2):
            left=i+1
            right=len(arr)-1
            while left < right:
                currentSum = arr[i] + arr[left] + arr[right]
                if abs(target-currentSum) < abs(target - closestSum):
                    closestSum = currentSum
                elif abs(target - currentSum) == abs(target - closestSum):
                    closestSum = min(closestSum, currentSum)
                if currentSum < target:
                    left += 1
                elif currentSum > target:
                    right -= 1
                else:
                    return currentSum
        return closestSum
```

---

# Complexity

- **Time Complexity:** `O(n²)`
  - Sorting takes `O(n log n)`.
  - The outer loop runs `n` times, and the two pointers traverse the remaining array once for each iteration.
  - Overall complexity is **O(n²)**.

- **Space Complexity:** `O(1)`
  - Only a few extra variables are used.
